## English

> ChatGPT Local Files is an open-source Windows setup kit for ordinary ChatGPT Chat to read, edit, save local files, and run installed commands through a private MCP tunnel. Inference stays in ChatGPT Chat; the kit makes no model API calls. Independent task backends and file-version checks help concurrent workflows. Give the kit to your own Codex for setup and real Chat verification. Each user needs their own account with the required tunnel/custom MCP features. https://github.com/jayhigh425/chatgpt-local-files

Suggested title: **Let ChatGPT Chat work with your local Windows files — an open-source MCP setup kit**

## A useful demonstration

1. Create a disposable `notes.md` with two or three paragraphs, with no personal data.
2. Ask ordinary Chat to read it, improve one paragraph, save the result, and reread it.
3. Show the real saved file and verification result. Keep credentials, account IDs, private paths, and unrelated browser tabs out of the recording.

For technical communities, include the architecture, installation prerequisites, and validation limits. For users, show the local file changing and link directly to the latest release. Publish to outside communities only from an account whose owner has authorized that post.
